# research-synth

1. 원문은 `knowledge/research/_private/`에 두고 커밋하지 않는다.
2. 원문에서 사실(관찰·발언)과 해석을 구분해 뽑는다. 발언은 화자 역할만 남기고 실명은 지운다.
3. `insights.md`에 추가: `- [영역-번호] 인사이트 — 근거 [src: 날짜 자료명 §위치]`. 영역: NAV, ENG, ISS, HIC, SHR(육상), AI, GEN.
4. 기존 인사이트와 중복이면 근거만 추가한다.
5. 요구사항으로 이어지는 것은 `requirements.md`에 `REQ-xx` (출처 인사이트 id 연결)로 추가.
6. 디자인 시스템에 영향이 있으면(새 상태, 새 컴포넌트 필요 등) 마지막에 "DS 영향" 목록으로 따로 보고한다.
7. 미결 사항·질문은 `open-questions.md`로.
