# Maritime rules

이 스킬은 **참조형**입니다. 다른 스킬(ds-component-build, screen-compose, ds-audit, Critic)이 이 규칙으로 검사합니다.
규칙의 근거 원문 요약은 `knowledge/standards/`, `knowledge/hiconis-philosophy.md`에 있습니다. 규칙과 근거가 충돌하면 근거를 따르고 이 파일 수정을 제안하세요.

## 경보·상태 (ALM)
- ALM-01 경보 색은 `status.alarm|warning|caution` 토큰만 사용. 같은 hue를 장식·브랜드에 쓰지 않는다.
- ALM-02 상태는 색 + (아이콘 | 형태 | 텍스트) 중 하나 이상을 함께 쓴다.
- ALM-03 comm-loss(통신 단절)는 정상 값처럼 보이면 안 된다: 값 감춤/해칭 + 아이콘.
- ALM-04 경보 우선순위가 높은 것이 시각적으로 항상 위에 온다 (순서, 크기, 위치).
- ALM-05 명령값과 실제 상태가 다를 수 있다 — 명령 진행 중 상태를 표현한다.

## 테마 (THM)
- THM-01 테마 4종(bright·day·dusk·night) 전부에서 텍스트 대비 기준 충족 (기준값은 표준 검토 후 확정, 임시 4.5:1).
- THM-02 night: 넓은 면적의 밝은 배경 금지, 경보 외 고채도 금지.
- THM-03 테마 전환은 Variable mode 전환만으로 동작해야 한다 (하드코딩 색이 있으면 실패).

## 조작 (INP)
- INP-01 터치 타깃 최소 48×48px (브리지 터치 디스플레이).
- INP-02 원격 제어 가능한 장비와 현장 수동 장비를 형태로 구분한다.
- INP-03 제어 동작은 확인 단계를 둔다 (대상·명령·결과 표시).

## AI 에이전트 (AIA)
- AIA-01 AI 제안은 감지 → 분석 → 근거 → 대응안 → **사용자 승인** 순서를 따른다. 자동 실행처럼 보이면 안 된다.
- AIA-02 AI 출처·확신도를 표시하고, 사람의 판단 영역과 시각적으로 구분한다.

## HiCONiS 호환 (HIC)
- HIC-01 매질별 배관 색은 `medium.*` 토큰만 사용 (필로소피 문서 기준).
- HIC-02 기존 공정도 사용자의 학습된 의미(색·심볼)를 바꿀 때는 변경 사유를 `mapping/`에 기록한다.
